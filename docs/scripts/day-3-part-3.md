# Day 3 · Part 3: The discussion

Sarah explains Part 3 and teaches one habit: say what you think, say why, give an example. The learner picks a theme and answers four questions. Sarah reads each question aloud and names what to cover.

**Prototype:** https://prototype-day3.vercel.app  
**Sections:** 21  
**Voice-over:** 62 lines, about 3m 53s of speech (one theme), plus the time the learner spends answering  
**Audio files:** 86, covering both themes

## Voices

| Voice | Direction |
|---|---|
| **Sarah** | the teacher. Warm, clear, unhurried. Talking to one person. She also reads the four questions aloud. |

## How to read this

- Each **section** is one screen in the prototype, in the order the learner sees it.
- Each **row** is one line of speech and becomes **one audio file**. Keep every row as its own clip. Its length decides when the caption changes and when that line's animation happens. Two rows merged into one file would put the animations out of step.
- File names: `d3-<section>-<line>.mp3`, with the theme in the middle when a section changes by theme (`d3-10-tech-1.mp3`).
- Sections marked *no voice-over* are where the learner does something: tapping, writing or speaking.
- The learner picks a theme (**Technology** and **Education**). Sections that change with it list both versions. Record both.
